# 🤖 DRC Robot PCB

Custom PCB for a differential-drive robotics competition robot.

## Overview
This board integrates:
- Raspberry Pi Pico
- Dual motor driver
- 2S LiPo power input (VBAT)
- Regulated 5V logic rail
- Encoder headers
- LED expansion headers

Designed as a 2-layer PCB for low-cost fabrication (e.g., JLCPCB).

---

## Power System
- **Battery:** 2S LiPo (~7.4V nominal)
- **VBAT:** Motor power
- **+5V:** Logic + peripherals
- **GND:** Common ground plane
